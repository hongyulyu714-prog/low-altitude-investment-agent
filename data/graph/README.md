# 产业链 V1 的来源与核验状态

本目录交付 35 个节点、50 条关系、25 家公司映射和 10 条事件规则。

## 核验口径

- 民航局《高质量发展通用航空和低空经济》可作为整机、基础设施和应用场景的宏观背景，不能单独证明碳纤维、结构胶、BMS、传感器等具体技术节点及连接关系。这些技术节点已改为 `pending_verification`。
- 现有关系的来源是宏观政策、发展规划或法律背景，尚未逐条定位证明该连接和成立条件的直接原文。50 条关系保留为候选结构，均标为 `pending_verification`；后续应补充官方技术文件或公司产品资料，并记录可定位的原文位置后逐条核验。
- 10 条事件规则是待核验的分析假设。引用政策背景不代表该事件的影响方向或传导条件已经获得事实支持。规则仅在自身依据完成核验、且路径中的每条关系均为 `verified` 时才能标为 `verified`。
- `RULE_SUBSIDY_POLICY_V1` 只保留 eVTOL → 充换电路径，适用范围必须明确覆盖航空充换电保障并产生新增补能需求；不再因共享补能概念延伸到农林植保。
- 公司映射的既有核验状态与产品匹配度估计口径保持不变。

## 验证

运行 `python scripts/validate_graph_data.py` 和 `python -m unittest discover -s tests -v`。
校验通过表示字段、引用和路径结构符合交付约定；不代表来源已经证明具体产业关系，也不代表待核验规则可作为已核验结论使用。
