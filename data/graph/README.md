## 使用口径

`verified` 表示节点定义或成立条件下的技术/应用连接获得直接来源支持，不表示相关公司受益或利润方向已经核验。技术关系中的 `positive` 表示功能支持；事件经济影响必须单独核验。正式规划、开发方案和试飞资料均明确限制适用阶段，不能用于宣称设施已部署或航空器已获商业运行许可。

型号配置和外国技术实例不能自动外推为所有低空机型配置、A股供应链或中国运行许可。钛合金节点有航空材料研究依据，通航/eVTOL具体装机关系仍待核验。

补贴规则仅保留 eVTOL → 充换电，要求具体政策覆盖适配航空充换电保障并产生新增补能需求；没有这样一份政策时仍是待核验假设，不延伸到农林植保。

公司映射的产品匹配度估计及既有核验状态保持原交付口径，本次来源核查覆盖节点、关系及事件规则。

## 验证

运行 `python scripts/validate_graph_data.py` 和 `python -m unittest discover -s tests -v`。

校验器检查主表与核查记录一致、覆盖完整、来源日期有效、已核验记录有直接来源及定位，并拒绝已核验规则依赖待核验关系。校验通过不会替代人工阅读全文和事实核查。
