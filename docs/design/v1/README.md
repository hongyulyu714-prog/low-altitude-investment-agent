## 设计与实现对应

- 1440×1024保持图谱y296、高540、净画布388、公司区y860。柔和蓝白背景来自A矢量导出；白色20px卡片、12px内部表面及低强度阴影保留。
- 来源类别图标使用A实际SVG导出，保持54px圆节点、20px图标、14px外置标签。当前节点只有一个16%蓝色光环；路径成员使用较轻描边，正/负/中性/不确定分别保留线型与文字。
- 保留已批准的初始自动聚焦辅助。用户手动平移、缩放或拖节点后立即进入保持视角；普通节点/路径选择不再移动相机。显式聚焦只居中，保持当前缩放。概览按实际范围调整，可回溯。
- 路径导航、当前焦点、返回/前进/历史、聚焦、公司比较和研究入口留在图谱内，不出现原实验室候选切换器或状态造数面板。
- 100ms悬停预览、250ms离开宽限，预览不改变研究选择或相机。进入详情时才选中；阅读期间稳定节点。
- 研究现场包含视角、节点位置、路径、显现进度、选中项、主动筛选、表格排序/标签与滚动。逐层返回保存阅读位置；回图谱不自动重播路径。
- TEST高亮与主动筛选仅作用于TEST公司。业务表仍显示实际报告公司，不接受TEST映射。公司总分、方向、风险、证据不由前端重算。
- 保留 m/k/c Spring、径向≤2CSS px漂移、360+100ms路径显现、用户输入打断、暂停、Reduced Motion及性能降级。浏览器实测覆盖正常漂移、选中稳定、暂停和中断；不声称已测试生产大图上限。

## 组件复用与来源

Figma直接克隆A完整可编辑子树，沿用Cambridge节点/类别图标/曲线实例与已有L01变量；BankDash表面、描边按钮、行分隔线和表格布局保留。新增空间控制、业务ID视图和状态面使用相同变量与圆角。正式React复用原实验室经验证的状态/动效思路并按职责拆分，未复制实验切换器或合成评分。

网页品牌、日历、四类节点图标与背景保留A导出SVG；Roboto/Noto字体携带原许可文本。没有引入BankDash或Cambridge整套前端源码。已有 `react-force-graph-2d` 依赖保留，本版空间图使用SVG，使确定位置、曲线、外置标签与可中断相机符合已选体验。

1. API分项与完整候选集的契约语义；节点/边/规则/公司映射是否由对应负责人补齐。
