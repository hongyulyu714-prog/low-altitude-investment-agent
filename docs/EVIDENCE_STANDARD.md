# 事件与证据标准 V1

数据版本：`event-evidence-v1-2026-10-12`。本交付服务 Issue #4，收录历史事件用于检索与评测，采集日期为 2026-10-12。历史文件发布事实不等于政策在采集日仍然有效，亦不等于相关公司当前受益。

## 文件与字段

`data/events.csv` 和 `data/evidence.csv` 的列名及顺序与仓库模板完全一致，使用 UTF-8、逗号分隔、标准 CSV 引号和 LF 换行。`affected_node_ids` 用分号分隔；JSON 数组字段不使用字符串拼接。

| 文件 | 用途 |
| --- | --- |
| `data/events.csv` | 30 条事件，类别配额为政策 8、公司 8、适航/许可 4、材料 4、应用 6 |
| `data/evidence.csv` | 31 条原始证据，按 `event_id` 关联，保留短摘录和定位；含跨年价格比较的基期片段 |
| `tests/test_cases.json` | 30 个问题，含预期路径、方向、企业类型、必需证据、答案要点与禁止推断 |
| `data/evidence_nodes.csv` | 本证据模块的临时节点字典，供图谱负责人对齐 |
| `data/evidence_review.json` | 数据版本、逐条来源复核日期、事件日期依据及人工审阅状态 |
| `docs/EVIDENCE_REVIEW.md` | 首批 10 条及随机抽查 10 条的定位记录和限制 |

事件字段：`event_id` 为稳定 ID；`event_name` 只描述一件发生的事；`event_type` 为下表枚举；`event_date` 为发生日期或明确说明的统计期末；`region` 为适用地域；`direction` 为条件性行业影响；`affected_node_ids` 为研究涉及的节点；`source_title/source_url/source_level` 指向主证据；`verification_status` 表示事件事实核验状态。

证据字段：`evidence_id` 为稳定片段 ID；`event_id` 指向事件；`source_title/publisher/published_date/source_url` 保留来源身份和发布时间；`quote` 为连续短摘录，不翻译或改写；`location` 为正文小标题、段落检索锚点或 PDF 页码；`claim_supported` 为限定范围的事实释义；`credibility_level` 为来源等级。由于模板未设证据核验状态，按 `event_id` 继承事件状态，逐条复核信息另存 `evidence_review.json`，不擅改模板。

| `event_type` | 说明 |
| --- | --- |
| `policy` | 已发布的政策、规划、条例、补贴和设施方案 |
| `corporate` | 上市公司公告/官网披露的订单、合作、融资、产品及建设进展 |
| `certification` | 适航审查进展、TC/PC/OC、空域或试点许可 |
| `material` | 材料及关键零部件价格或供给变化 |
| `application` | 物流、巡检、应急、文旅等实际应用及示范设施落地 |

`direction` 使用 `positive/negative/uncertain`。利好是对所列研究场景的潜在支持，不是证券回报预测。材料降价可能利好下游降本并压制上游售价，因此整体采用 `uncertain`；审查尚未作出结论也采用 `uncertain`。

## 日期、来源与状态

1. 政策以正文落款成文日期记录事件；公布条例以公布日期记录。施行日期、印发日期、网页发布时间可不同，差异写入复核记录。上海正文成文日为 7 月 25 日，页面印发日为 7 月 26 日、发布日为 8 月 16 日。安徽转载元数据与正文不同，以正文 4 月 1 日为依据。
2. 公司公告若未独立给出签约日期，则事件记录为公开披露日期，并在 `event_date_basis` 中说明。新闻发布日不能自动冒充底层签约日。
3. 年度价格统计以年度末记录，投资者交流区间以区间末记录。这是期间事件，不能解释为该日价格突然变动。时间区间写入 `event_date_basis`。
4. 来源日期按所链接页面的发布日保留，政府官方转载还应明确原发布机构与转载单位。不得从抓取日期推断发布日期。
5. A：政府、民航主管部门、交易所、指定披露平台及正式公告。B：公司官网/IR 及自发布新闻稿。C：权威媒体和行业协会。D：自媒体、论坛、聚合站，仅供检索线索。公司官网自述按 B 记录，不能仅因公司上市而提高为 A。
6. `verified` 仅表示已读取原始正文、核对事件日期、来源、短摘录、位置与事实范围。它不核验财务影响、图谱边、当前政策有效性或企业盈利。缺字段、链接失效、只有搜索摘要或未找到原始依据时使用 `pending_verification`，不进入评分关键证据。
7. 采集时来源正文通过网页读取工具核对；本机直接 HTTP 请求会遭遇部分站点 TLS、403 或 405 限制。不能将 HTTP 可访问性检查和内容核验混为一谈，也不保证未来 URL 永久可用。重跑时重新打开原链接，失败就保留错误并暂停使用该条。

本批公司事件包含在美国上市的亿航及其 A 股/港股合作伙伴。事件事实库不限 A 股；后续 Wind 公司评分必须根据公司映射确认具体上市主体、证券代码及权益，不把集团或子公司合作直接计入上市公司营收。本批 8 条公司事件集中于亿航生态，不能用于评价全行业代表性。

## 摘录与事实边界

每段只保留支撑必要事实的短句，不储存网页或公告全文。中文片段优先控制在一句，英文片段控制在 25 词以内。英文标题和原文保持原语言；中文释义仅放在 `claim_supported`。PDF 页码以文件页序及印刷页码共同定位，本批中复神鹰记录两者均为第 2 页。

- 30 架采购协议、270 架计划、实际交付分别记录，不能叠加成为确定订单；祥源 50 架计划与首批 5 架订单也应分开。
- MoU/战略合作和拟设合资公司不等于量产供货、项目投产或已确认收入。
- TC 是型号审定，PC 是生产质量体系，OC 是运营人的运行许可；还应核验单机适航等条件。监管 PC 来源明确颁发日为 2024-03-28，企业 4 月对外公告不能覆盖该日期。
- 亿航 TC 的企业颁证仪式公告使用 2023-10-13；监管后续回顾提到 10 月 12 日。`EVT_002` 精确描述为“亿航宣布获得TC”，不将公告日冒称为证书签发日。
- 首飞、展示中心或枢纽启用不等于获准常态化收费运营。不得将后来取得的 OC 回填为更早事件时已有资质。
- 工信部锂盐/电芯行业价格不是航空级电池报价。由 `EVD_003_BASE` 和 `EVD_008` 同口径年度碳酸锂均价计算 `(9.0/25.8-1)*100 ≈ -65.1%`，不能用该比例直接计算航空器成本下降。
- 光威设计产能不是实际产量，也不能认定全部供给航空客户。T300/T700市场价格回落无统一降幅，不能编造百分比。

## 评测、节点与 RAG 使用

评测题每题关联事件及至少一条该事件证据。跨年比较题额外引用另一事件的证据。`expected_path` 是有条件的研究路径，可能包括需求向上游传导，不能默认都是供应链物理流向；`conditions` 明确成立条件，`not_supported` 指明应拒绝的过度结论。

当前 `main` 没有 `data/graph/nodes.csv`、关系或正式接口，本批使用 `NODE_EVID_` 命名空间和 `pending_graph_alignment` 状态，不覆盖 Issue #2 的节点资产。每题保留 `path_status=hypothesis_pending_graph_validation`。集成前由图谱负责人按名称/语义映射到正式节点，更新事件和评测题，验证每一条边、方向、条件及规则；本地节点存在不能证明生产图谱已可查询。

RAG 可用一行证据作为一个可引用片段，保留全部来源字段与 `event_id/evidence_id`。检索先按事件、区域、时间和来源等级过滤，生成结果显式引用证据 ID。只把 `claim_supported` 中被支持的事实当作已核验内容；条件性路径、价格对利润的影响及具体公司财务重要性需要图谱和 Wind 模块另行提供依据。本 Issue 不增加向量库或后端接口。

## 验证与审阅

仓库根目录运行，无额外依赖：

```bash
python scripts/validate_evidence.py
python -m unittest discover -s tests -p 'test_*.py'
```

校验模板列顺序、类别配额、首 10 条覆盖、唯一 ID、日期、URL 结构、来源等级、事件/证据/评测外键、节点字典及研究路径状态。单元测试包含重复 ID、缺摘录、无效日期、孤立证据和来源等级降级等错误输入。网络可访问性、摘录语义和页面定位仍须来源复核，不能由离线 PASS 代替。

首 10 条已由 Codex 逐条阅读原文，随机种子 `4` 从全部 30 条抽取 10 条再核对；记录见复核文档。仓库要求的团队成员人工核验尚待 PR 审阅人签核，`human_review_status` 保持 `pending`，不能把自动校验冒充人工验收。审阅人确认后更新状态、日期和署名。

所有输入来自公开政府文件、公司官网或指定披露平台，未使用 Wind 原始导出、账号、Cookie、密钥或受限研报全文。本批摘录用于证据定位与研究，来源 URL 保留原发布者权利信息，不声称获得来源全文的再分发许可。
