# 吕洪宇页位术语表

| 术语 | 本计划书中的固定含义 | 禁止混用的表述 |
| --- | --- | --- |
| 事件 | 有ID、日期、方向、来源和核验状态的研究输入 | 将任意自然语言或新闻标题直接称为已核验事件 |
| 路径 | 由相邻节点、关系、规则、方向和证据组成的传导链 | 将TEST图或孤立节点称为已验证业务路径 |
| 公司影响分 | `Exposure × Sensitivity × FinancialMateriality / 10000`的确定性计算结果 | 收益预测、估值判断、公司质量评分 |
| 影响方向 | `positive`、`negative`、`neutral`或`uncertain`的单独字段 | 由分数高低自动推导方向 |
| 财务重要性代理 | 评分公式中的放大程度代理 | 健康度、信用评级或完整财务评价 |
| 证据 | 有来源、日期、URL、短摘录、定位和状态的可回查材料 | 只有链接、无定位的泛化引用 |
| Mock | 用于接口、交互或代码复现的模拟数据 | 真实市场数据、已验证研究结论 |
| 待集成 | 已存在独立资产但尚未进入当前主链路 | 已上线、当前报告已经使用 |
